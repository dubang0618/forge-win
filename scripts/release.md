# 发布新版本指南

## 1. 准备发布

### 更新版本号
编辑 `package.json`，修改 `version` 字段：
```json
{
  "version": "1.0.4"
}
```

### 构建和打包
```bash
# 安装依赖（如果需要）
pnpm install

# 构建前端
pnpm build

# 打包应用
pnpm package
```

打包完成后，安装包位于 `dist/` 目录：
- Windows: `Forge Code Setup 1.0.4.exe`
- 自动更新文件: `latest.yml`

## 2. 发布到 Gitee

### 创建 Release
1. 访问 Gitee 仓库页面
2. 点击 "发行版" → "创建发行版"
3. 填写信息：
   - **标签名称**: `v1.0.4` (必须以 v 开头)
   - **发行版标题**: `v1.0.4`
   - **发行说明**: 描述本次更新内容

### 上传文件
上传以下文件到 Release：
- `Forge Code Setup 1.0.4.exe` (安装包)
- `latest.yml` (更新配置文件，必须上传)

### 发布
点击 "发布" 按钮完成发布。

## 3. 用户端自动更新

用户启动应用后：
1. 应用自动检查 Gitee Releases 是否有新版本
2. 如果有新版本，后台静默下载
3. 下载完成后弹窗提示用户重启更新
4. 用户点击"立即更新"后自动安装并重启

## 4. 注意事项

- 版本号必须遵循语义化版本规范 (如 1.0.4)
- Gitee Release 标签必须以 `v` 开头 (如 v1.0.4)
- 必须同时上传 `.exe` 和 `latest.yml` 文件
- `latest.yml` 文件由 electron-builder 自动生成，包含版本信息和文件哈希
- 只有生产版本会检查更新，开发模式不会触发更新检查

## 5. 测试更新

发布后可以用旧版本测试：
1. 安装旧版本应用
2. 启动应用
3. 查看控制台日志确认更新检查
4. 等待更新下载完成
5. 测试更新安装流程
